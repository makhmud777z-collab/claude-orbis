# Кликабельный прототип

Один HTML-файл без сборщика и сервера: открывается двойным кликом и
показывает портал целиком — настраиваемое меню, канбан с перетаскиванием,
карточки с историей, умный фильтр во всех разделах, календарь по часам,
живую структуру компании, обе темы, закрытое кодом администрирование
с воронками и правами, и каталог вузов.

Код входа в «Администрирование» — `7777`, как и в приложении.

Нужен для показа: клиенту не нужно ставить Node, а ссылка открывается
с телефона. Данные берутся не из отдельного мока, а **из тех же сидов,
что и продукт** — иначе прототип разошёлся бы с системой за неделю.

```bash
npx tsx scripts/prototype/data.ts   # выгрузить данные из src/lib/data
node scripts/prototype/build.mjs    # собрать build/prototype.html
node scripts/prototype/check.mjs    # прогнать браузером (нужен playwright)
```

## Что внутри

| Файл | Что делает |
|---|---|
| `data.ts` | выгружает сиды и справочники в `build/data.json` |
| `head.html` / `body.html` | оболочка: палитра, типографика, каркас страницы |
| `src/01-core.js` | язык, даты, деньги, версии продукта, права, меню, иконки |
| `src/02-matching.js` | подбор вуза — перенесён из `src/lib/matching.ts` без изменений |
| `src/03-state.js` | состояние, зоны видимости, воронки, дедупликация, рабочий день |
| `src/04-ui.js` | кирпичики разметки: канбан, история, полоса стадий, свои списки, умный фильтр и его поля по разделам |
| `src/05…08` | экраны |
| `src/09-shell.js` | меню, шапка с живым счётчиком дня и переключателем темы, маршруты, действия, перетаскивание |
| `build.mjs` | склеивает всё в один файл |
| `check.mjs` | браузерный прогон: ошибки JS, пустые экраны, доска, дубли, фильтр, тема, календарь, структура, замок настроек, меню, роли, язык |

Модули нумерованы, потому что порядок в собранном файле имеет значение:
справочники и состояние объявляются раньше экранов, которые их читают.

## Ограничения

Прототип держит изменения в памяти вкладки: перенос карточки, отметка
рабочего дня, правка стадии и прав, сохранённые фильтры и новые отделы живут
до перезагрузки. Шорт-лист вузов и выбранная тема сохраняются в
`localStorage`. Это витрина, а не вторая реализация продукта: всё, что
требует настоящего сохранения, живёт в приложении.

Демо-данные стоят на 16 сентября 2026 года — это «сегодня» портала, и по
нему выделяется число в календаре. Красная линия в дневном срезе и счётчик
рабочего дня идут по настоящим часам компьютера: иначе их нечего было бы
показывать.

Карточку сотрудника прототип не правит — кнопка «Изменить» объясняет, что
делает продукт. Всё остальное из корректировок работает вживую.
