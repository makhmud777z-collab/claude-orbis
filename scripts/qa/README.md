# Прогон проверок

Скрипты гоняют собранное приложение браузером и ловят то, что не видит
TypeScript: пустые экраны, сорванную вёрстку, доступ мимо прав, утечку данных
между агентствами.

```bash
# playwright уже в devDependencies; браузер ставится один раз:
npx playwright install chromium
npx tsx scripts/qa/integrity.ts  # целостность данных, браузер не нужен
node scripts/qa/i18n.mjs         # забытые переводы, браузер не нужен

npm run build && npm start       # для остальных нужен поднятый сервер
node scripts/qa/crawl.mjs        # все маршруты × 3 агентства × 2 языка
node scripts/qa/roles.mjs        # навигация и доступ для всех 8 ролей
node scripts/qa/flows.mjs        # канбан, дубли, конвертация, фильтр, тема, календарь
node scripts/qa/layout.mjs       # горизонтальная прокрутка на 390 и 810px
node scripts/qa/spacing.mjs      # ничто не вылезает за свой блок
node scripts/qa/mobile-nav.mjs   # меню на телефоне

npm run qa                       # всё подряд

Переменные: `QA_BASE_URL` — адрес приложения (по умолчанию localhost:3000),
`CHROMIUM_PATH` — путь к готовому браузеру, если он уже установлен в системе.
```

Каждый скрипт печатает либо «прошли», либо список проблем и завершается
ненулевым кодом — их можно ставить в CI. Скриншоты складываются в `shots/`.

## Что именно проверяется

- **integrity** — ссылки между сущностями, суммы, наборы и дедлайны вузов,
  принадлежность программ, оплата не больше договора. Плюс правила CRM:
  у каждой воронки есть финальная стадия и ровно одна воронка по умолчанию,
  стадия сделки существует в её воронке, цвет стадии — корректный HEX,
  и **ни один телефон не встречается дважды** среди контактов и активных
  лидов одного агентства.
- **i18n** — узбекский перевод не является копией русского.
- **crawl** — HTTP-коды, ошибки консоли, «undefined» и «[object Object]» в
  тексте, непереведённая навигация, а также изоляция: чужая запись обязана
  дать 404 или заглушку версии и не показать ни одного поля.
- **roles** — меню каждой из 8 ролей содержит всё положенное и ничего лишнего
  (разделы раскрываются, подпункты учитываются), прямой заход в закрытый
  раздел даёт заглушку.
- **flows** — сквозные сценарии CRM:
  - карточка переносится по доске мышью, и перенос попадает в историю сделки;
  - комментарий из карточки сохраняется и появляется в ленте;
  - второй лид на тот же номер не создаётся: форма показывает существующую
    карточку и блокирует сохранение;
  - конвертация лида открывает созданную сделку и пишет запись в историю;
  - рабочий день начинается и завершается из меню профиля, счётчик идёт
    вживую и останавливается на перерыве;
  - переименование и перекраска стадии доезжают до доски;
  - умный фильтр: поиск и пресет сужают список, снятие чипа возвращает
    записи, условия остаются в адресе страницы;
  - переключение темы переживает переход на другую страницу;
  - в дневном срезе календаря стоит красная линия текущего времени;
  - «Отмена» закрывает каждое из семи всплывающих окон;
  - выпадающий список внутри панели фильтра не обрезается самой панелью;
  - «Канбан» и «Список» — два вида одного раздела, и список рисует таблицу;
  - структура компании рисует дерево и показывает подчинённых в правой
    панели;
  - шорт-лист не течёт между студентами, фильтры и поиск сужают выдачу,
    язык живёт между страницами, лента не показывает чужую активность.
- **layout** — горизонтальной прокрутки нет ни на одном экране; при её
  появлении скрипт падает, а не просто печатает число.
- **spacing** — ни один блок не вылезает за свои границы: 28 экранов на
  четырёх ширинах и двух языках. Ловит подпись, вылезшую за карточку,
  кнопку, не влезшую в панель, строку, обрезанную краем блока. Многоточие
  (`truncate`) — осознанное решение, такие элементы пропускаются.
