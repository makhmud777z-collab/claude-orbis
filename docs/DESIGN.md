# Дизайн-система

Основа — `DESIGN-framer.md` (тёмный холст, плакатная типографика, пилюли,
единственный синий акцент). Структура экранов — из референса CRM: рельса
навигации слева, шапка с поиском, канбан-доска с карточками. Светлый референс
пересобран в тёмном: берётся композиция, а не палитра.

## Токены

Объявлены в `src/app/globals.css` через `@theme`.

| Слой | Значение | Где |
|---|---|---|
| canvas | `#090909` | фон страницы, шапка, рельса |
| surface-1 | `#141414` | карточки, поля ввода, вторичные кнопки |
| surface-2 | `#1c1c1c` | активный пункт меню, выбранный чип, поднятые карточки |
| hairline | `#262626` | границы | 
| hairline-soft | `#1a1a1a` | разделители внутри карточек |
| ink / ink-muted / ink-faint | `#fff` / `#999` / `#6b6b6b` | три ступени текста |
| accent | `#0099ff` | только ссылки, фокус и выделение |

Иерархия на тёмном строится подъёмом поверхности (canvas → surface-1 →
surface-2), а не прозрачностью белого.

## Типографика

Inter Variable с включёнными начертаниями `cv01 cv05 cv09 cv11 ss03 ss07`.
Дисплейные размеры держат отрицательный трекинг по проценту от кегля
(−1.4px на 32px, −3.1px на 62px). Табличные цифры — класс `.t-num`: в CRM
колонки с деньгами и процентами обязаны выравниваться.

GT Walsheim не открытый шрифт — по рекомендации самого гайда его заменяет Inter
с ручным поджатием трекинга.

## Цвет статусов

Гайд запрещает второй хроматический акцент. CRM без цветовых статусов
нечитаема, поэтому компромисс: **статусы носят точки 6px и тонкие полосы
прогресса, но никогда — заливки**. Чип статуса остаётся `surface-1` с серым
текстом, цвет несёт только точка. Синий `accent` при этом не расходуется на
статусы и остаётся сигнальным.

Шкала: новый — оранжевый, открыт — синий, в процессе — янтарный, успех —
зелёный, риск — коралловый, ожидание — серый, подбор — фиолетовый.

## Компоненты

- Кнопки — только пилюли: белая (основная), угольная (вторичная), призрачная.
  Квадратных CTA в системе нет.
- Карточки — 15px радиус, поднятые — 20px, атмосферные панели — 30px.
- Градиентная «прожекторная» карточка используется **один раз на экран** —
  на дашборде, как вход в подбор вузов. Больше — уже мудборд.
- Фокус — синее кольцо `rgba(0,153,255,.15)`, единственное хроматическое
  указание глубины.
- Поверх холста лежит едва заметное зерно (2.5%), чтобы чёрный не выглядел
  плоским.

## Адаптив

- Рельса навигации скрывается ниже 1024px, в шапке появляется кнопка меню:
  панель выезжает слева поверх контента и закрывается при переходе.
- Панель рендерится через портал в `body`. У шапки есть `backdrop-blur`, а он
  создаёт containing block для `position: fixed` — иначе панель обрезается по
  высоте шапки. Это ловушка, на которую легко наступить повторно.
- Горизонтальной прокрутки страницы быть не должно ни на одном экране:
  колонки сеток и flex-элементы получают `min-w-0`, широкие таблицы
  прокручиваются внутри себя (`.scroll-x`).
- Проверяется скриптом: `node scripts/qa/layout.mjs` (390px и 810px).

## Правила, которые легко нарушить

1. Не добавлять цветные заливки под статусы.
2. Не уменьшать отрицательный трекинг на заголовках «ради читаемости» —
  уменьшать кегль.
3. Не ставить вторую градиентную карточку на тот же экран.
4. Не вводить четвёртую ступень серого текста: `ink`, `ink-muted`, `ink-faint`
   и всё.
